# Security policy

Micorra holds credentials for your boards and repositories, so we treat security reports as the
highest priority.

## Reporting a vulnerability

- Use **GitHub private vulnerability reporting**: the "Report a vulnerability" button in this
  repository's **Security** tab.
- **Do not** open a public issue, discussion or pull request for a vulnerability.
- Include the version, your platform, the steps to reproduce and the impact you observed.

We acknowledge reports within 5 business days and keep you informed until a fix is released. We
credit reporters in the release notes unless you prefer otherwise.

## Supported versions

Until 1.0, only the latest release receives security fixes.

## Scope

In scope: the Micorra daemon, CLI, dashboard and official templates in this repository.
Out of scope: vulnerabilities in third-party MCP servers or AI clients themselves — report those to
their maintainers.
